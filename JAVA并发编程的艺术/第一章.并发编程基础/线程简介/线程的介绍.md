学习多线程要先回答两个问题：**[[什么是线程]]** 和 **[[为什么要使用多线程]]**——前者定义了线程是操作系统调度的最小单元，后者解释了多线程如何通过充分利用 CPU 资源来提升系统吞吐量。理解了这两个概念，才能知道应该在什么合适的情况下用对应的方法。而在使用线程时，有三组特性直接影响程序的正确性和健壮性：**[[线程的优先级]]** 只是一层薄弱的建议，**不能作为程序正确性的唯一依赖**；**[[线程的状态]]** 是排查死锁和阻塞问题的核心依据，6 种状态及转换条件需要烂熟于心；最容易被忽视的是 **[[Daemon 线程]]**，它的 **`finally` 块不可靠**，JVM 退出时不会等它收尾，因此**绝对不能把释放关键资源的代码单独寄托在守护线程上**。这三者共同构成了线程基础的核心安全边界
