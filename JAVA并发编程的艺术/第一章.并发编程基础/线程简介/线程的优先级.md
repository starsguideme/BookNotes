- **核心机制：时间片分时调度**
    
    - 现代 OS 通过**时间片**轮转调度线程。
        
    - 线程用完分配给它的时间片后，会被挂起，等待下次调度。
        
    - **优先级的作用**：决定线程**能获得多少时间片**。优先级越高，被分配的时间片通常越多，也就能获得更多的处理器资源。
        

### 第二段核心：Java 层面的优先级映射

- **控制与范围**
    
    - Java 中通过整型变量 `priority` 控制线程优先级。
        
    - **范围是 `1` 到 `10`**，默认值是 **`5`**。
        
    - 通过 `Thread.setPriority(int)` 方法进行设置。
        
- **使用策略**
    
    - **频繁阻塞的任务（I/O 密集型）**：设置**较高**优先级。因为它们多数在等待，不会长时间占用 CPU。
        
    - **偏重计算的任务（CPU 密集型）**：设置**较低**优先级，防止它们独占处理器。
        
- **关键警示：不可完全依赖优先级**
    
    - **这是你笔记里最关键、最容易踩坑的结论**：
        
        1. **宿主环境差异**：不同的 JVM 和操作系统对优先级的映射和调度实现存在差异。
            
        2. **被忽略的风险**：有些操作系统甚至会直接忽略 Java 线程优先级
