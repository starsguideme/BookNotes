
### 一、三个核心类

Java 提供了三种原子更新基本类型的类：

| 类名 | 说明 |
|------|------|
| ==**`AtomicBoolean`**== | 原子更新布尔类型 |
| ==**`AtomicInteger`**== | 原子更新整型（`int`） |
| ==**`AtomicLong`**== | 原子更新长整型（`long`） |

这三个方法的内置方法几乎是一样的，它们的底层都是通过 `volatile` + `CAS` 来实现原子操作。

### 二、通用方法

以下是它们的通用方法：

| 方法 | 说明 |
|------|------|
| ==**`int addAndGet(int delta)`**== | 以原子方式将输入的值与实例中的值进行相加后返回结果 |
| ==**`boolean compareAndSet(expect, update)`**== | 如果输入的数值等于预期值，则以原子方式将该值设置为输入的值 |
| ==**`int getAndIncrement()`**== | 以原子方式将当前值加 1，返回旧值 |
| ==**`void lazySet(int newValue)`**== | 让其他线程在短时间内可以访问到其旧值，但最终会使其变成新值 |
| ==**`int getAndSet(int newValue)`**== | 以原子方式设置为新值，但返回旧值 |

### 三、使用示例

```java
// AtomicInteger 示例
AtomicInteger count = new AtomicInteger(0);

count.addAndGet(5);       // 原子地加 5，返回新值 5
count.getAndIncrement();  // 原子地自增，返回旧值 5，新值变为 6
count.compareAndSet(6, 10); // 如果当前值是 6，则设置为 10，返回 true
count.lazySet(20);         // 延迟写入，最终会变成 20
count.getAndSet(30);       // 原子地设置为 30，返回旧值 20
```

### 四、适用范围

| 适用场景 | 说明 |
|---------|------|
| ==**计数器/序列号生成**== | 如统计请求数量、生成唯一 ID |
| ==**状态标志位**== | 如 `AtomicBoolean` 用于控制线程启动/停止 |
| ==**需要原子更新的单个变量**== | 如库存扣减、余额更新 |

| 不适用场景 | 说明 |
|-----------|------|
| ==**多个变量同时更新**== | 原子类只能保证单个变量的原子性，多个变量同时更新需要使用锁 |
| ==**频繁更新的场景**== | CAS 自旋会消耗 CPU，竞争激烈时性能反而低于锁 |
| ==**需要条件等待的场景**== | 原子类不支持 `wait/notify`，需要条件等待时应使用锁 |

### 五、面试要点

| **问题**                  | 回答                                                   |
| ------------------- | ---------------------------------------------------- |
| **原子更新基本类型有哪三种**        | ==**`AtomicBoolean`、`AtomicInteger`、`AtomicLong`**== |
| **`compareAndSet` 的作用** | 如果当前值等于预期值，则**原子地设置为新值**，否则不做任何操作                    |
| **`lazySet` 的特点**       | 其他线程在短时间内可能看到旧值，但**最终会变成新值**                         |
| **原子类的底层实现**            | ==**`volatile` + `CAS`**==                           |
| **原子类和锁的区别**            | 原子类无锁、无阻塞、无上下文切换，适用于**单个变量**的原子更新                    |
