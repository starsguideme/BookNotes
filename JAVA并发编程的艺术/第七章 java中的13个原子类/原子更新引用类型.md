



### 一、三个核心类

Java 提供了三种原子更新引用类型的类：

| 类名 | 说明 |
|------|------|
| ==**`AtomicReference`**== | 原子更新引用类型，保证对象引用的原子更新 |
| ==**`AtomicReferenceFieldUpdater`**== | 原子更新引用类型的字段，通过反射方式更新指定类的 `volatile` 字段 |
| ==**`AtomicMarkableReference`**== | 原子更新带有标记位的引用类型，可以原子更新一个引用类型和一个布尔类型的标记位 |

### 二、各类的核心作用

**1. AtomicReference**

对普通的对象引用进行原子更新，底层通过 `volatile` + `CAS` 实现。适用于需要原子地替换整个对象的场景。

**2. AtomicReferenceFieldUpdater**

通过反射的方式，原子地更新某个类中指定的 `volatile` 引用类型字段。它的优势在于**不需要修改原有类的定义**，可以直接对现有类中的字段进行原子操作。

**3. AtomicMarkableReference**

可以原子地更新一个引用类型和一个**布尔类型的标记位**。它的作用是解决 CAS 中的 **ABA 问题**——通过标记位来判断引用是否被修改过，类似于 `AtomicStampedReference`（但 `AtomicStampedReference` 使用的是整数版本号，`AtomicMarkableReference` 使用的是布尔标记位）。

### 三、三类原子更新的汇总对比

| 类别 | 核心类 | 说明 |
|------|--------|------|
| ==**原子更新基本类型**== | `AtomicBoolean`、`AtomicInteger`、`AtomicLong` | 原子更新 `boolean`、`int`、`long` 类型 |
| ==**原子更新数组**== | `AtomicIntegerArray`、`AtomicLongArray`、`AtomicReferenceArray` | 原子更新整型、长整型、引用类型数组的元素 |
| ==**原子更新引用类型**== | `AtomicReference`、`AtomicReferenceFieldUpdater`、`AtomicMarkableReference` | 原子更新对象引用、字段、带标记位的引用 |

### 四、适用范围

| 适用场景 | 说明 |
|---------|------|
| ==**需要原子更新对象的场景**== | 如需要原子地替换整个对象引用 |
| ==**需要对已有类的字段进行原子操作**== | 使用 `AtomicReferenceFieldUpdater`，无需修改原有类 |
| ==**需要解决 ABA 问题的场景**== | 使用 `AtomicMarkableReference` 或 `AtomicStampedReference` |

| 不适用场景 | 说明 |
|-----------|------|
| ==**需要同时更新多个字段的场景**== | 原子类只能保证单个引用或字段的原子性 |
| ==**需要条件等待的场景**== | 原子类不支持 `wait/notify`，需要条件等待时应使用锁 |

### 五、面试要点

| 问题                                | 回答                                                                                |
| --------------------------------- | --------------------------------------------------------------------------------- |
| **原子更新引用类型有哪三种**                      | ==**`AtomicReference`、`AtomicReferenceFieldUpdater`、`AtomicMarkableReference`**== |
| **`AtomicMarkableReference` 的作用**     | 原子更新一个引用类型和一个**布尔标记位**，解决 ABA 问题                                                  |
| **`AtomicReferenceFieldUpdater` 的特点** | 通过**反射**更新指定类的 `volatile` 字段，不需要修改原有类                                             |
| **原子更新的三大类别**                         | ==**基本类型、数组、引用类型**==                                                              |
