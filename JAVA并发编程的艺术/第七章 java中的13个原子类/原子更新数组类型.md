

**原子更新数组**

### 一、三个核心类

Java 提供了三种原子更新数组的类：

| 类名 | 说明 |
|------|------|
| ==**`AtomicIntegerArray`**== | 原子更新整型数组中的元素 |
| ==**`AtomicLongArray`**== | 原子更新长整型数组中的元素 |
| ==**`AtomicReferenceArray`**== | 原子更新引用类型数组中的元素 |

### 二、常用方法

以 `AtomicIntegerArray` 为例，其常用方法如下：

| 方法 | 说明 |
|------|------|
| ==**`int addAndGet(int i, int delta)`**== | 以原子方式将输入值与数组中索引 `i` 对应的元素相加，返回新值 |
| ==**`boolean compareAndSet(int i, int expect, int update)`**== | 如果当前值等于预期值，则以原子方式将数组索引 `i` 对应的元素更改为 `update` |
| ==**`int getAndIncrement(int i)`**== | 以原子方式将索引 `i` 的元素加 1，返回旧值 |
| ==**`int getAndSet(int i, int newValue)`**== | 以原子方式将索引 `i` 的元素设置为 `newValue`，返回旧值 |
| ==**`void lazySet(int i, int newValue)`**== | 延迟设置，最终会将索引 `i` 的元素设置为 `newValue` |

与[[原子更新基本类型]]一样，这些方法在原子更新中都是通用的，底层同样是通过 `volatile` + `CAS` 来实现原子操作。

### 三、使用示例

```java
// 创建原子整型数组
int[] arr = {1, 2, 3, 4, 5};
AtomicIntegerArray atomicArr = new AtomicIntegerArray(arr);

atomicArr.addAndGet(0, 10);     // 索引 0 的元素原子加 10 → 11
atomicArr.getAndIncrement(1);   // 索引 1 的元素原子自增，返回旧值 2 → 新值 3
atomicArr.compareAndSet(2, 3, 100); // 索引 2 当前值是 3，设置为 100，返回 true
atomicArr.lazySet(3, 200);      // 延迟设置索引 3 为 200
atomicArr.getAndSet(4, 500);    // 索引 4 设置为 500，返回旧值 5
```

### 四、适用范围

| 适用场景 | 说明 |
|---------|------|
| ==**需要原子操作数组元素的场景**== | 如多线程下统计多个计数器、更新多个状态值 |
| ==**需要 CAS 更新数组元素的场景**== | 如多个线程同时修改同一个数组的不同元素 |

| 不适用场景 | 说明 |
|-----------|------|
| ==**需要整体保护数组的场景**== | 原子类只保证单个元素的原子性，不能保证数组整体的数据一致性 |
| ==**元素之间存在关联的场景**== | 如果多个元素之间有逻辑关联，需要使用锁来保护整个操作 |
| ==**频繁更新的场景**== | CAS 自旋会消耗 CPU，竞争激烈时性能反而低于锁 |

### 五、面试要点

| 问题                   | 回答                                                                    |
| -------------------- | --------------------------------------------------------------------- |
| **原子更新数组有哪三种**       | ==**`AtomicIntegerArray`、`AtomicLongArray`、`AtomicReferenceArray`**== |
| **原子数组和普通数组的区别**     | 原子数组可以保证**单个元素**的原子更新，普通数组没有这个保证                                      |
| **原子数组能保证整个数组的一致性吗** | ==**不能**==，只能保证单个元素的原子性，整体一致性需要锁                                      |
| **原子数组的底层实现**        | ==**`volatile` + `CAS`**==                                            |
