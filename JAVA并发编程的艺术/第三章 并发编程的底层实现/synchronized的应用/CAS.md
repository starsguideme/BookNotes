### 一、定义

CAS 全称 Compare And Swap，即**比较并交换**。它是处理线程之间**同步**问题的主流方案之一。CAS 在**软件层面**是无锁的——**线程不会阻塞，也不会进入 BLOCKED 状态**——但在**硬件层面**，CPU **通过 Lock 前缀指令或原子指令**（如 `cmpxchg`）保证比较并交换这个操作的原子性，相当于在硬件上加了锁。

### 二、执行流程

CAS 操作包含三个操作数：内存位置 **V**、旧的预期值 **A**、新的值 **B**。执行步骤如下：

1. **先记录预期值 A**：从内存 V 中读取当前值，作为预期值 A。
    
2. **比较**：再次读取内存 V 的当前值，与预期值 A 进行对比。
    
3. **如果相等**，说明在读取之后没有其他线程修改过 V，此时将 V 原子地更新为 B。
    
4. **如果不相等**，说明在读取之后有其他线程修改过 V，此时不做任何操作，返回当前 V 的值。
    

**无论是否更新成功，CAS 都会返回 V 原有的值**。

### 三、乐观锁与悲观锁

CAS 体现了两种不同的锁策略：

| 策略          | 执行方式               | 对应实现                           |
| ----------- | ------------------ | ------------------------------ |
| ==**乐观锁**== | 先操作，没有冲突就成功，有冲突就重试 | CAS 自旋（`AtomicInteger`）        |
| ==**悲观锁**== | 先锁住资源，确保没有冲突再操作    | `synchronized`、`ReentrantLock` |

CAS 本身就是乐观锁策略的典型实现——它假定冲突很少发生，每次直接尝试修改，如果失败就重新读取再尝试，直到成功。这种方式在竞争不激烈时效率远高于悲观锁，因为**省去了线程阻塞和唤醒的上下文切换开销。**

### 四、ABA 问题

由于 CAS 本身只比较"值是否相同"，**会产生 ABA 问题**：

**场景**：一个共享变量 V 的初始值为 A。

1. 线程 1 读取 V 的值为 A，准备修改为 C。
    
2. 在线程 1 执行 CAS 之前，线程 2 将 V 从 A 改为 B，又从 B 改回了 A。
    
3. 线程 1 执行 CAS 时，发现 V 仍然是 A，认为没有发生过变化，将 V 更新为 C。
    

虽然最终 V 的值是 C，但**中间发生了两次修改**，线程 1 完全没有感知到。这种"值相同但中间被改过"的情况就是 ABA 问题。

**解决方案**：通过**加版本号**来解决。`AtomicStampedReference` 在维护值的同时维护一个整数版本戳（Stamp），每次更新时同时修改值和时间戳。CAS 比较时同时检查值和版本戳，即使值相同，只要版本戳不对，CAS 也会失败。

### 五、自旋 CAS 的问题

如果 CAS 长时间不成功，它会一直循环重试，不断消耗 CPU 资源。这就是为什么 `synchronized` 的轻量级锁在自旋超过一定次数后会升级为重量级锁——自旋空耗 CPU 的总开销已经超过了线程阻塞的上下文切换开销，此时让线程进入 BLOCKED 状态反而更划算。

### 六、面试要点

| 问题                        | 回答                                                               |
| ------------------------- | ---------------------------------------------------------------- |
| **CAS 是软件层面的还是硬件层面的？**        | 软件层面是无锁的（线程不阻塞），硬件层面通过 CPU 原子指令保证了操作的原子性                         |
| **ABA 问题是什么？怎么解决？**           | 值从 A 变到 B 再变回 A，CAS 检测不到中间的变化。通过加版本号（`AtomicStampedReference`）解决 |
| **CAS 和 `synchronized` 的区别？** | CAS 乐观，不阻塞线程；`synchronized` 悲观，获取不到锁时阻塞线程，涉及上下文切换                |
| **自旋 CAS 有什么缺点？**             | 长时间自旋空耗 CPU，竞争激烈时需要升级为重量级锁                                       |
