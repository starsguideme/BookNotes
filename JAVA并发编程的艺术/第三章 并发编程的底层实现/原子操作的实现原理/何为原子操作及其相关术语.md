### 一、原子操作的定义

原子操作的意思是**不可被中断的一个或一系列操作**。要么全部执行完毕，要么完全不执行，中间不会有任何其他操作插入进来。

### 二、相关术语表

| 中文术语            | 英文术语                   | 定义                                                                                              |
| --------------- | ---------------------- | ----------------------------------------------------------------------------------------------- |
| ==**缓存行**==     | Cache Line             | 缓存的最小操作单位，通常为 64 字节。CPU 与主内存之间交换数据时，以缓存行为单位进行加载或回写                                              |
| ==**比较并交换**==   | Compare And Swap       | CAS 操作包含三个操作数——内存位置 V、旧的预期值 A、新的值 B。当 V 的当前值等于 A 时，将 V 更新为 B，否则不做任何操作。CAS 是一条原子指令，在硬件层面保证操作的原子性 |
| ==**CPU 流水线**== | CPU Pipeline           | 将一条指令的完整执行过程拆分为多个步骤（取指、解码、执行、访存、写回），每个步骤由独立的电路单元并行处理，像工厂装配流水线一样可以同时处理多条指令的不同阶段，大幅提升 CPU 指令执行效率  |
| ==**内存顺序冲突**==  | Memory Order Violation | 当两个线程修改的不同变量落在同一个缓存行中时，每次修改都会导致对方的缓存行失效，CPU 需要重新从内存加载数据。这种由伪共享引起的频繁失效与重载就是内存顺序冲突，会严重拖慢程序执行速度    |

### 三、面试要点

| 问题          | 回答                                           |
| ----------- | -------------------------------------------- |
| 原子操作的含义     | 不可被中断的一个或一系列操作，要么全部执行，要么全部不执行                |
| CPU 流水线的作用  | 将一条指令拆分为多个阶段并行处理，使 CPU 能同时处理多条指令的不同阶段，提高执行效率 |
| 内存顺序冲突由什么引起 | 伪共享——两个线程修改的不同变量落在同一个缓存行中，导致缓存行频繁失效和重载       |
| 如何避免内存顺序冲突  | 通过缓存行填充（追加字节到 64 字节），让关键变量独占一个缓存行            |
