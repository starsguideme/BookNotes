

**独占式同步状态的获取**

### 一、`acquire(int arg)` 方法概述

通过使用同步器中的 `acquire(int arg)` 方法可以获取同步状态。该方法对中断不敏感——线程无论成功还是失败获取同步状态，仍可进入同步队列中。哪怕线程被中断了，线程也不会被移除 AQS。

### 二、`acquire` 方法的执行流程

```text
acquire(arg)
    ↓
① tryAcquire(arg) —— 尝试获取锁（由子类实现）
    ↓
    ├── 成功 → 直接返回，线程持有锁
    │
    └── 失败 → 进入同步队列
              ↓
        ② addWaiter(Node.EXCLUSIVE) —— 以互斥模式构建节点，CAS 加入队尾
              ↓
        ③ acquireQueued(node, arg) —— 进入自旋等待，不断尝试获取锁
              ↓
              ├── 前驱节点是头节点且 tryAcquire 成功 → 将自己设为头节点，返回
              │
              └── 获取失败 → shouldParkAfterFailedAcquire 检查是否需要阻塞
                            ↓
                         parkAndCheckInterrupt 阻塞线程
```

**核心逻辑**：

1.  首先调用自定义的同步组件来实现第一次获取线程状态的方法（`tryAcquire`），该方法可以保证线程安全的获取同步状态。
2.  如果没有获取到，则会以**互斥锁**的方式来构建同步节点（`addWaiter`），并通过 CAS 将目标节点中的数据加入到 AQS 的尾部。
3.  最后使用 `acquireQueued` 方法，让该目标节点以**长期自旋**的方式获取同步状态。在其自旋时如果没获取到同步状态，则阻塞节点中的线程来达到互斥的操作。

### 三、唤醒阻塞线程的两种方式

| 唤醒方式 | 说明 |
|---------|------|
| ==**队列中的首个节点出队**== | 前驱节点是头节点，且当前节点成功获取锁，则将当前节点设为新的头节点，原头节点出队 |
| ==**阻塞操作被中断**== | 线程在阻塞期间被 `interrupt()` 中断，从 `parkAndCheckInterrupt` 返回 |

### 四、`addWaiter` 与 `enq` 的线程安全机制

`addWaiter` 使用 `compareAndSetTail(期望值，待修改的节点)` 方法确保节点可以以**线程安全**的方式完成修改的操作。

在 `enq(final Node node)` 中，同步器以**长期自旋**的方式来保证节点的正确添加。在自旋中只有通过 CAS 将目标节点设置为链表的尾节点时，线程才能返回，否则当前线程将一直处于等待并自旋的状态中。

```text
enq(node) 的执行流程：
    ↓
① 获取当前尾节点 t
    ↓
② 如果 t == null（队列为空），CAS 创建头节点并初始化
    ↓
③ CAS 将当前节点设为尾节点
    ↓
    ├── CAS 成功 → 将前驱节点的 next 指向当前节点，返回
    │
    └── CAS 失败 → 重新自旋，继续尝试
```

因此 `enq(final Node node)` 方法可以将多线程并发向队列发送添加节点的请求，通过 CAS 来实现以**单线程的模式**下完成线程安全性的添加操作。

### 六、面试要点

| 问题                | 回答                                             |
| ----------------- | ---------------------------------------------- |
| **`acquire` 方法的核心流程** | ==**tryAcquire → addWaiter → acquireQueued**== |
| **获取锁失败后如何入队**        | 通过 `addWaiter` 以互斥模式构建节点，CAS 加入队尾              |
| **入队后如何等待获取锁**        | 通过 `acquireQueued` 以**长期自旋**的方式不断尝试获取锁         |
| **唤醒阻塞线程的方式**         | ==**前驱节点释放锁后唤醒后继节点**==，或**阻塞被中断**              |
| **`enq` 如何保证线程安全**    | 通过**自旋 CAS** 设置尾节点，失败则重新自旋，直到成功                |
