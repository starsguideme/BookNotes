

**读写锁的接口与示例**

### 一、ReadWriteLock 接口

`ReadWriteLock` 仅定义了获取读锁和写锁两个方法：

| 方法                | 说明                    |
| ----------------- | --------------------- |
| **==`readLock()`==**  | 获取读锁，多个线程可以同时持有读锁     |
| **==`writeLock()`==** | 获取写锁，同一时刻只有一个线程可以持有写锁 |

### 二、ReentrantReadWriteLock 的外部监控方法

`ReentrantReadWriteLock` 除了一些接口方法，还有一些便于外部监视工作状态的方法：

| 方法 | 说明 |
|------|------|
| ==**`int getReadLockCount()`**== | 返回当前读锁被获取的次数 |
| ==**`int getReadHoldCount()`**== | 返回当前线程持有读锁的次数（可重入次数） |
| ==**`boolean isWriteLocked()`**== | 判断写锁是否被某个线程持有 |
| ==**`int getWriteHoldCount()`**== | 返回当前线程持有写锁的次数（可重入次数） |

### 三、使用读写锁实现线程安全的 Cache

读写锁可以用来确保 Cache 线程安全的。读操作的 `get` 方法不会使其他线程阻塞，写操作的 `put` 方法在更新哈希表时必须提前获取写锁。当获取到写锁时，其他线程（包括读线程和其他写线程）均会被阻塞。

由于读写锁的特性，必须先释放写锁才能完成读锁操作。Cache 对读写锁进行了优化，其可以提高并发性，保证每次写操作对所有的读操作都有可见性。

**示例代码**：

```java
import java.util.HashMap;
import java.util.Map;
import java.util.concurrent.locks.ReadWriteLock;
import java.util.concurrent.locks.ReentrantReadWriteLock;

public class Cache {
    private final Map<String, Object> map = new HashMap<>();
    private final ReadWriteLock rwLock = new ReentrantReadWriteLock();

    // 读操作，使用读锁，多个线程可以同时读取
    public Object get(String key) {
        rwLock.readLock().lock();
        try {
            return map.get(key);
        } finally {
            rwLock.readLock().unlock();
        }
    }

    // 写操作，使用写锁，同一时刻只有一个线程可以写入
    public void put(String key, Object value) {
        rwLock.writeLock().lock();
        try {
            map.put(key, value);
        } finally {
            rwLock.writeLock().unlock();
        }
    }

    // 清空缓存，使用写锁
    public void clear() {
        rwLock.writeLock().lock();
        try {
            map.clear();
        } finally {
            rwLock.writeLock().unlock();
        }
    }
}
```

### 四、面试要点

| 问题                    | 回答                                           |
| --------------------- | -------------------------------------------- |
| **ReadWriteLock 接口有哪些方法** | ==**`readLock()`**== 和 ==**`writeLock()`**== |
| **如何用读写锁实现线程安全的 Cache**   | 读操作使用读锁（多个线程可同时读），写操作使用写锁（独占，阻塞其他线程）         |
| **写操作时为什么需要阻塞读操作**        | 保证每次写操作对所有的读操作都有**可见性**，防止读到脏数据              |
| **读写锁比互斥锁的优势**            | 读操作之间不互斥，多个读线程可以并发执行，提高吞吐量                   |
