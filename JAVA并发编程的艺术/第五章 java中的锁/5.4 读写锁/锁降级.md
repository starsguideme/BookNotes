

**锁降级**

### 一、锁降级的定义

锁降级指的是**无可逆转地从写锁变成读锁**。大致意思为：在持有写锁的同时获取了读锁，并将写锁释放的操作叫做锁降级。其执行顺序为：

```text
① 获取写锁
    ↓
② 获取读锁（在写锁持有期间）
    ↓
③ 释放写锁（此时仍持有读锁）
    ↓
④ 完成锁降级，线程仅持有读锁
```

### 二、为什么需要锁降级？

锁降级的主要目的是**保证可见性**。一个线程在持有写锁时修改了共享数据，如果在释放写锁之前先获取读锁，就可以确保其他线程在写锁释放后无法立即获取写锁来修改数据，从而保证本线程能读到刚刚修改的值，而不是被其他线程修改后的新值。这在数据一致性要求高的场景下非常重要。

### 三、为什么不能锁升级？

锁降级是可逆的，但**锁升级是不允许的**。如果多个线程同时持有读锁，其中一个线程尝试获取写锁（锁升级），就会产生**死锁**也无法对其他线程具有可视性——因为写锁需要等待所有读锁释放，而该线程自己就持有一个读锁，形成了互相等待的局面。
