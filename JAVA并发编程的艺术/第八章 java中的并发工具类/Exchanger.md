
### 一、核心定位

Exchanger 是一个用于**线程间协作**的工具类，主要用于**线程间的数据交换**。它内部提供一个同步工具，在这个同步工具中，两个线程可以交换彼此的数据。

### 二、核心机制

两个线程可以提供 `exchange()` 方法来交换数据。如果第一个线程先执行 `exchange()` 方法，它会**一直等待**第二个线程也执行 `exchange()` 方法。只有两个线程都到达了同步工具后，这两个线程就会开始交换数据，将生产者线程的数据给予消费者线程。

```text
线程 A 调用 exchange(V dataA)
    ↓
线程 A 阻塞等待
    ↓
线程 B 调用 exchange(V dataB)
    ↓
双方交换数据：
线程 A 收到 dataB
线程 B 收到 dataA
    ↓
双方继续执行
```

### 三、使用限制

Exchanger 的作用一般是可用于处理类似的两者之间的数据交换。一旦两者中有一方线程处于**等待状态或阻塞**，则这两个线程会一起被阻塞，无法继续执行。但可以通过设置**过期时间**来断开这种状态，使用 `exchange(V x, long timeout, TimeUnit unit)` 方法在超时后自动返回。

### 四、适用范围

| 适用场景 | 说明 |
|---------|------|
| ==**两个线程之间的数据交换**== | 如生产者与消费者之间直接交换数据 |
| ==**遗传算法中的交叉操作**== | 两个个体之间交换基因数据 |
| ==**校对工作**== | 两个线程分别处理同一份数据，然后交换结果进行校对 |

| 不适用场景 | 说明 |
|-----------|------|
| ==**多个线程之间的数据交换**== | Exchanger 只适用于**两个线程**，多线程应使用 `BlockingQueue` 或 `TransferQueue` |
| ==**单方面的数据传输**== | 如果只需要将数据从一个线程传给另一个线程，使用 `SynchronousQueue` 或 `BlockingQueue` 即可 |
| ==**需要可靠性的场景**== | 一方线程阻塞会导致另一方永久等待，应设置超时时间 |
