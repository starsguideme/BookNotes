
### 一、Fork/Join 框架的设计理念

由[[Fork框架与工作窃取算法]]得知，Fork/Join 框架的主要目的是切割大任务分成若干个小任务进行并发处理，最后返回大任务。因此就可以得到其设计的理念：

| 阶段                | 说明                                       |
| ----------------- | ---------------------------------------- |
| ==**分割任务**==      | 将一个大任务递归地 fork 成若干个更小的子任务，直到子任务足够小可以直接执行 |
| ==**执行任务并合并结果**== | 将每个子任务分配至不同线程并发执行，最后将所有子任务的结果合并成最终结果     |

### 二、Fork/Join 框架的核心 API

| API | 说明 |
|-----|------|
| ==**`ForkJoinTask`**== | 提供在任务中执行 `fork()` 和 `join()` 操作的机制，一般不会直接使用这个接口，而是使用其子类 |
| ==**`RecursiveAction`**== | 用于**没有返回结果**的任务 |
| ==**`RecursiveTask`**== | 用于**有返回结果**的任务 |
| ==**`ForkJoinPool`**== | `ForkJoinTask` 需要通过 `ForkJoinPool` 线程池来执行 |

**使用步骤**：

1.  **创建任务**：继承 `RecursiveTask`（有返回值）或 `RecursiveAction`（无返回值），重写 `compute()` 方法。
2.  **分割任务**：在 `compute()` 方法中判断任务是否足够小，如果是则直接执行；否则分割成子任务，调用 `fork()` 提交子任务。
3.  **合并结果**：调用 `join()` 等待子任务执行完毕，合并子任务的结果后返回。

### 三、工作窃取算法在 Fork/Join 中的应用

任务分割出的子任务会添加到当前工作线程所维护的**双端队列的头部**（作为 LIFO 栈使用，后进先出）。如果此时队列中没有任何任务或线程时，它会尝试从**其他队列中工作队列的尾部**获取到一个可执行的任务（作为 FIFO 队列使用，先进先出）。

```text
工作窃取流程：

线程 A 双端队列：  [任务1, 任务2, 任务3]  ← 头部（自己从头部取，LIFO）
                  ↑                    ↑
                  自己操作端         窃取端（其他线程从尾部取，FIFO）

线程 B 自己的队列为空时：
    ↓
从线程 A 的队列尾部窃取任务 → 减少竞争（双方操作不同端）
```

### 四、适用范围

| 适用场景                     | 说明                           |
| ------------------------ | ---------------------------- |
| ==**计算密集型递归任务**==        | 如归并排序、快速排序、斐波那契数列等天然适合分治的任务  |
| ==**需要充分利用多核 CPU 的场景**== | 通过并行执行子任务提高 CPU 利用率          |
| ==**大数据量处理**==           | 如大规模数组求和、矩阵运算等可以被拆分成独立子任务的计算 |

| 不适用场景                 | 说明                                  |
| --------------------- | ----------------------------------- |
| ==**I/O 密集型任务**==     | I/O 密集型任务更适合使用线程池，工作窃取对 I/O 等待无明显优化 |
| ==**任务之间依赖复杂的场景**==   | 如果子任务之间有强依赖关系，Fork/Join 的分治模型不适用    |
| ==**任务数量少或粒度不均的场景**== | 可能导致线程间负载不均衡，甚至只有一个线程在干活            |

### 五、面试要点

| 问题                  | 回答                            |
| ------------------- | ----------------------------- |
| **Fork/Join 框架的设计理念**   | ==**分割任务 + 执行任务并合并结果**==      |
| **有返回值的任务用什么类**         | ==**`RecursiveTask`**==       |
| **无返回值的任务用什么类**         | ==**`RecursiveAction`**==     |
| **ForkJoinTask 通过什么执行** | ==**`ForkJoinPool`**== 线程池    |
| **工作窃取时子任务放在队列的哪一端**    | 放在**头部**（自己从头部取），窃取线程从**尾部**取 |
