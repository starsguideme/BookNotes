
### 一、三种核心线程池

线程池执行器一般情况下使用工厂类 `Executors` 来创建，其可以创建三种类型的线程池执行器：

| 类型                             | 核心特点                | 适用场景                               |
| ------------------------------ | ------------------- | ---------------------------------- |
| ==**`FixedThreadPool`**==      | **固定数量的线程池**        | 需要在限制当前线程数量下，使用合理的管理资源，比较重的负载的服务器中 |
| ==**`SingleThreadExecutor`**== | **只有一个线程的线程池**      | 保证任务的执行有序性，同时保证了任务的原子性（串行执行）       |
| ==**`CachedThreadPool`**==     | **无界的线程池，线程数可动态扩展** | 短期较多的异步任务或负载较轻的服务器中                |

### 二、三种线程池的详细说明

**1. FixedThreadPool**

固定数量的线程池，核心线程数和最大线程数相等。适用于负载较重、需要限制线程数量的服务器中，通过固定线程数来控制资源的使用。

**2. SingleThreadExecutor**

只有一个线程的线程池，核心线程数和最大线程数都为 1。适用于需要保证任务执行**有序性**的场景，由于所有任务串行执行，天然保证了任务的原子性。

**3. CachedThreadPool**

无界的线程池，核心线程数为 0，最大线程数为 `Integer.MAX_VALUE`。线程数可根据需要动态扩展，适用于短期较多的异步任务或负载较轻的服务器中。

### 三、三种线程池的构造参数对比

| 类型 | 核心线程数 | 最大线程数 | 工作队列 | 线程存活时间 |
|------|----------|----------|---------|------------|
| ==**`FixedThreadPool`**== | `n` | `n` | `LinkedBlockingQueue`（无界） | 0 |
| ==**`SingleThreadExecutor`**== | 1 | 1 | `LinkedBlockingQueue`（无界） | 0 |
| ==**`CachedThreadPool`**== | 0 | `Integer.MAX_VALUE` | `SynchronousQueue` | 60 秒 |

### 四、面试要点

| **问题**                             | 回答                                                                                                           |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| **`Executors` 可以创建哪三种线程池**         | ==**`FixedThreadPool`、`SingleThreadExecutor`、`CachedThreadPool`**==                                          |
| **三种线程池的使用场景**                     | `FixedThreadPool` 适用于负载较重的服务器；`SingleThreadExecutor` 适用于需要保证任务有序性的场景；`CachedThreadPool` 适用于短期较多异步任务或负载较轻的服务器 |
| **`SingleThreadExecutor` 如何保证原子性** | 只有一个线程，所有任务**串行执行**，天然保证原子性                                                                                  |
| **`CachedThreadPool` 的线程存活时间**     | ==**60 秒**==，空闲线程超过 60 秒会被回收                                                                                 |
