
### 一、框架的三大部分

Executor 框架主要由三部分组成：

| 部分 | 包含内容 | 说明 |
|------|---------|------|
| ==**任务**== | `Runnable` 接口与 `Callable` 接口 | 定义需要执行的任务 |
| ==**任务的执行**== | `Executor` 接口、`ExecutorService` 接口、`ThreadPoolExecutor`、`ScheduledThreadPoolExecutor` | 负责任务的调度与执行 |
| ==**异步计算的结果**== | `Future` 接口和 `FutureTask` 类 | 表示异步计算的结果 |

### 二、框架核心成员

| 成员 | 说明 |
|------|------|
| ==**`ThreadPoolExecutor`**== | 线程池的核心类，用于执行被提交的任务 |
| ==**`ScheduledThreadPoolExecutor`**== | 实现类，可以在给定的延迟后运行命令，或者定期执行命令。该类比 `Timer` 更灵活，功能也更强 |
| ==**`Future`**== | 代表着异步计算的结果 |
| ==**`Runnable` / `Callable`**== | 主要是线程池类和可延迟化的线程池类的实现接口 |

### 三、框架结构图

```text
Executor 框架的层次结构：

任务接口层
├── Runnable（无返回值）
└── Callable（有返回值）

任务执行层
├── Executor（顶层接口，定义了 execute(Runnable)）
│   └── ExecutorService（扩展接口，增加了 submit、shutdown 等方法）
│       ├── ThreadPoolExecutor（线程池核心实现类）
│       └── ScheduledThreadPoolExecutor（延迟/定时任务实现类）
│
└── Executors（工厂类，用于创建各种线程池实例）

异步计算结果层
├── Future（表示异步计算的结果）
└── FutureTask（同时实现 Runnable 和 Future）
```

接口的实现请参考[[Executor执行步骤]]。

在 Executor 中也有其相应的成员，详细参考[[Executor框架的属性]]。

### 四、面试要点

| 问题                                          | 回答                                                                                    |
| ------------------------------------------- | ------------------------------------------------------------------------------------- |
| **Executor 框架由哪三部分组成**                          | ==**任务、任务的执行、异步计算的结果**==                                                              |
| **任务执行层的核心接口和类**                                | `Executor` → `ExecutorService` → `ThreadPoolExecutor` / `ScheduledThreadPoolExecutor` |
| **`ScheduledThreadPoolExecutor` 比 `Timer` 的优势** | 更灵活，功能更强，支持多线程                                                                        |
| **`Future` 的作用**                                | 表示**异步计算的结果**，可以通过 `get()` 获取返回值                                                      |
