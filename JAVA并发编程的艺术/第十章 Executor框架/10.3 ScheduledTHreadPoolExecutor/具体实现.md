  
### 一、任务的成员变量

在[[运行机制]]中提到，`ScheduledThreadPoolExecutor` 会把待调度的任务放入到一个无界队列（`DelayQueue`）中。该任务一般会持有三种成员变量：

| 成员变量                     | 类型     | 说明                                            |
| ------------------------ | ------ | --------------------------------------------- |
| **==`time`==**           | `long` | 表示任务大概什么时候执行                                  |
| **==`sequenceNumber`==** | `long` | 表示这个任务被添加到 `ScheduledThreadPoolExecutor` 中的序号 |
| **==`period`==**         | `long` | 表示两个任务之间的间隔                                   |

### 二、任务的排序规则

无界队列通过封装一个**优先级队列**（`PriorityQueue`），这个优先级队列会对队列中的 `ScheduledFutureTask` 任务进行排序。排序时，`time` 小的在前。如果此时两个 `ScheduledFutureTask` 的 `time` 时间相同，就会比较其 `sequenceNumber`，其也是按**升序**的方式进行排序。

### 三、执行任务的四个步骤

| 步骤 | 操作 | 说明 |
|------|------|------|
| ==**步骤 1**== | 线程从 `DelayQueue` 中获取已到期的任务 | 到期任务是指 `ScheduledFutureTask` 的 `time` 大于或等于当前时间 |
| ==**步骤 2**== | 线程开始执行该任务 | 执行 `ScheduledFutureTask` 中的具体逻辑 |
| ==**步骤 3**== | 修改任务的下次执行时间 | 将 `ScheduledFutureTask` 的 `time` 变量设置成下次要执行的时间 |
| ==**步骤 4**== | 将任务放回 `DelayQueue` | 把修改 `time` 之后的 `ScheduledFutureTask` 放回到无界队列中 |

### 四、`DelayQueue` 获取任务的方法内部实现

`DelayQueue` 获取任务的内部实现主要分为以下步骤：

| 步骤 | 操作 | 说明 |
|------|------|------|
| ==**步骤 1**== | **获取 Lock 接口** | 内部通过被 `final` 修饰后的可重入锁（[[Reentrantlock]]）和 `lock` 的可中断方法来限制线程的读写 |
| ==**步骤 2**== | **获取周期性任务** | 判断此时的优先级队列是否为空：如果为空，将当前线程放入 `Condition` 中进行等待；如果不为空，进一步判断头元素的 `time` 是否比当前时间大 |
| ==**步骤 3**== | **判断是否需要超时等待** | 如果头元素的 `time` 比当前时间大，则等待到 `time` 时间结束；如果依旧没有到期，则继续等待 |
| ==**步骤 4**== | **获取优先级队列的头元素** | 如果头节点不为空，则唤醒在版本号中正在等待的所有线程（详细参考[[Reentrantlock]]） |
| ==**步骤 5**== | **释放 Lock** | 释放锁，完成本次获取 |

### 五、添加任务的代码实现

添加任务与获取任务的方式一样，都被分为三类：

| 步骤 | 操作 | 说明 |
|------|------|------|
| ==**步骤 1**== | **获取 Lock** | 获取可重入锁 |
| ==**步骤 2**== | **添加任务** | 向优先级队列添加任务；如果添加的任务是优先级队列的头元素，则唤醒版本号中等待的所有线程 |
| ==**步骤 3**== | **释放 Lock** | 释放锁，完成本次添加 |

### 六、`ScheduledThreadPoolExecutor` 的特殊处理

`ScheduledThreadPoolExecutor` 在上述基础上，在某个循环中一直用 **CAS** 来获取周期性任务，直到优先级队列获取到元素时，才会退出循环。

### 七、面试要点

| **问题**                                      | 回答                                                    |
| --------------------------------------- | ----------------------------------------------------- |
| **`ScheduledThreadPoolExecutor` 的任务排序规则**   | 按 **`time`** 升序排列，`time` 相同则按 **`sequenceNumber`** 升序 |
| **执行完周期性任务后如何处理**                           | 修改任务的 `time` 为下次执行时间，**重新放回 `DelayQueue`**            |
| **`DelayQueue` 获取任务时为空怎么处理**                | 将当前线程放入 **`Condition`** 中进行等待                         |
| **添加任务时如果是头元素怎么办**                          | 唤醒在版本号中**等待的所有线程**                                    |
| **`ScheduledThreadPoolExecutor` 如何获取周期性任务** | 在循环中用 **CAS** 获取，直到优先级队列获取到元素才退出                      |
