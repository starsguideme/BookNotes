### 一、并发编程的两个核心问题

在并发编程中，需要处理两个关键问题：**线程之间如何通信** 以及 **线程之间如何同步**。

|问题|含义|
|---|---|
|==**通信**==|线程之间通过什么机制来交换信息|
|==**同步**==|程序中用于控制不同线程间操作发生的相对顺序的机制|

### 二、两种并发模型

线程之间的通信机制一般有两种：**共享内存** 和 **消息传递**。

|并发模型|通信方式|同步方式|典型代表|
|---|---|---|---|
|==**共享内存**==|线程之间共享程序的公共状态，通过写-读内存中的公共状态进行**隐式通信**|同步是**显式**执行的，程序员必须显式指定某个方法或某段代码需要在线程之间互斥执行|Java|
|==**消息传递**==|线程之间没有公共状态，必须通过**显式发送消息**来进行通信|同步是**隐式**进行的，因为消息的接收必然发生在发送之后，天然确定了顺序|Erlang、Go的Channel|

### 三、Java的选择及其代价

Java 的并发采用的是**共享内存模型**，Java 线程之间的通信总是**隐式进行**的。这意味着：

- 程序员不需要显式发送消息，线程 A 修改一个共享变量，线程 B 读取即可。
    
- 但这种隐式通信在带来便利的同时，也带来了各种可见性、原子性、有序性问题——就像计算机网络从单机通信演进到分布式通信时，需要面对数据一致性、网络延迟等问题一样，Java 的多线程也经历了从原始到规范化的过程。

### 四、面试要点

|问题|回答|
|---|---|
|Java 采用什么并发模型|共享内存模型，线程之间通过写-读主内存中的公共状态进行隐式通信|
|共享内存和消息传递的区别|共享内存中通信是隐式的、同步是显式的；消息传递中通信是显式的、同步是隐式的|
|为什么隐式通信会带来问题|因为线程之间的通信不显式发生，编译器或处理器可能对指令进行重排序，导致另一个线程看到的执行顺序与代码顺序不一致，产生可见性和有序性问题|
