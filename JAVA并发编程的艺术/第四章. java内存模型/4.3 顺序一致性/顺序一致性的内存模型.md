### 一、两大特性

顺序一致性内存模型具有两大特性：

| 特性          | 说明                                             |
| ----------- | ---------------------------------------------- |
| ==**特性一**== | 一个线程中的所有操作必须按照程序的顺序来执行                         |
| ==**特性二**== | **所有线程都只能看到一个单一的操作执行顺序。每个操作都必须原子执行且立刻对所有线程可见** |
|             |                                                |

这两大特性合在一起，保证了在顺序一致性模型中，多线程程序的执行结果与所有线程的操作按某种顺序依次串行执行的结果完全一致。

### 二、线程与内存的关系

在顺序一致性模型中，线程与内存之间的关系是**一对多**的。这里的"多"是指多个线程共享同一个主内存，而不是内存起到线程池的作用——线程池是管理线程的机制，与内存模型的概念不同。

主内存的作用是：**控制着线程的读写操作的执行顺序，以及保证线程之间的可见性。所有线程的读写操作都直接与主内存交互，每个操作都是原子的且立即可见，因此天然具有有序性和可见性。**

### 三、顺序一致性与 JMM 的对比

| 维度       | 顺序一致性模型           | JMM                       |     |
| -------- | ----------------- | ------------------------- | --- |
| **执行顺序** | 严格按程序顺序执行         | 允许重排序，但不影响正确同步的程序         |     |
| **可见性**  | 每次读写都直接操作主内存，立即可见 | 通过 happens-before 规则保证可见性 |     |
| **性能**   | 低（禁止任何优化）         | 高（允许编译器和处理器优化）            |     |
| **实现方式** | 理论模型              | 实际规范，通过**[[内存屏障]]**实现     |     |

JMM 的设计目标是：**在保证正确同步的程序具有顺序一致性的前提下，尽可能允许编译器和处理器进行性能优化。**

### 四、面试要点

|问题|回答|
|---|---|
|顺序一致性模型的两大特性|① 线程内操作按程序顺序执行；② 所有线程看到统一的操作顺序，每个操作原子且立即可见|
|顺序一致性与 JMM 的关系|顺序一致性是理论模型，JMM 是实现规范。正确同步的程序在 JMM 中具有与顺序一致性模型相同的执行结果|
|为什么 JMM 不直接实现顺序一致性|完全的顺序一致性会禁止所有优化，性能太低。JMM 在保证正确性的前提下允许重排序和缓存优化|
