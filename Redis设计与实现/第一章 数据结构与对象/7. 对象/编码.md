1. 对象的Ptr指针指向着底层的数据结构，而数据结构的类型是由对象的encoding决定着

| 常用类型        | 编码                      |     | 对象                 |     |
| ----------- | ----------------------- | --- | ------------------ | --- |
| RedisStinrg | RedisEncodingInt        |     | 数值实现的字符串对象         |     |
| RedisString | RedisEncodingEmbstr     |     | 使用Embstr的简单动态字符串实现 |     |
| RedisString | RedisEncodingRaw        |     | 使用简单SDS实现的字符串对象    |     |
| RedisList   | RedisEncodingZipList    |     | 使用压缩链表的列表对象        |     |
| RedisList   | RedisEncodingLinkedList |     | 使用双端链表的列表对象        |     |
| RedisHash   | RedisEncodingZipList    |     | 使用压缩链表实现的哈西对象      |     |
| RedisHash   | RedisEncodingHT         |     | 使用字典实现的集合对象        |     |
| RedisSet    | RedisEncodingIntSet     |     | 使用字整数集合实现的集合对象     |     |
| RedisSet    | RedisEncodingHt         |     | 使用字典实现的集合对象        |     |
| RedisZset   | RedisEncodingZipList    |     | 使用压缩链表的有序列表对象      |     |
| RedisZset   | RedisEncodingSkipList   |     | 使用跳表和字典实现的有序集合对象   |     |
