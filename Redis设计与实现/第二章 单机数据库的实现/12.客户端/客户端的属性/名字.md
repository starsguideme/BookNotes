**客户端的名字属性（name）**

在默认情况下，每个连接到 Redis 服务器的客户端都是**无名**的，其 `name` 属性指向 `NULL`。

可以通过在客户端执行 ==**`CLIENT SETNAME`**== 命令来为客户端设置一个名字。设置之后，客户端的 `name` 属性会指向一个 SDS 字符串，用于存储这个名字。

| 状态        | name 属性值                        |
| --------- | ------------------------------- |
| 未设置名字（默认） | `NULL`                          |
| 已设置名字     | 指向一个 SDS 字符串（如 `"my-client-1"`） |
|           |                                 |
**注：SDS是一个字符串且类C类型的数据，详细情参考[[何为SDS及其作用]].**
**面试要点**：

`CLIENT SETNAME` 通常用于**调试和运维场景**。当你通过 `CLIENT LIST` 命令查看当前所有连接时，有名字的客户端更容易被识别出来，方便排查哪个业务模块的连接数异常，或者某个客户端是否长时间占用资源。它是一个非常实用的运维工具，而不仅仅是个“装饰”属性。
