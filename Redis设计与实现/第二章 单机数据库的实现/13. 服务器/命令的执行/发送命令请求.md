**命令请求的发送流程**

Redis 服务器的命令请求来源于客户端。当用户在客户端中输入一个命令请求时，整个过程可以分为以下两步：

**第一步：用户 → 客户端（输入命令请求）**

用户在客户端的交互界面中输入命令请求，如 `SET key value`。此时这个命令请求还只是一个普通的文本字符串。

**第二步：客户端 → 服务器（协议转换与发送）**

客户端接收到用户输入的命令请求后，会将其 ==**转换成 Redis 协议格式（RESP）**==，然后通过连接到服务器的套接字，将协议格式的命令请求发送给服务器。

整个数据流如下：
用户输入 "SET key value"
         ↓
客户端将命令转换为 RESP 协议格式
  例如: *3\r\n$3\r\`nSET`\r\n$3\r\nkey\r\n$5\r\nvalue\r\n
         ↓
通过 TCP 套接字发送给服务器
         ↓
服务器接收并处理（readQueryFromClient → `querybuf` → `argv`/`argc` → 命令执行器）
