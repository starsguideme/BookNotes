1. 过期键的定期删除由 `activeExpireCycle` 函数实现。每当 Redis 的周期性事件循环 `serverCron` 被执行时，会调用 `activeExpireCycle`，它会分多次对数据库的键空间随机检查，如果发现过期键则立即删除。
    
2. 定期删除策略的相关参数是可以设置的，例如调整每次执行的频率和每次检查的键数量。
    
3. `activeExpireCycle` 的工作方式如下：
    
    - 每次执行时，从一定数量的数据库中随机取出一定数量的键进行检查，删除其中已过期的键。
        
    - 全局变量 `current_db` 记录当前检查的数据库进度，下一次执行时从下一个数据库继续检查。
        
    - 当所有数据库都被检查完一遍后，`current_db` 重置为0，开始新一轮循环。
        
4. 这是一个随机抽查、分批次清理的策略，也是 Redis 实际采用的方案，和惰性删除配合使用，达到 CPU 和内存的平衡。
