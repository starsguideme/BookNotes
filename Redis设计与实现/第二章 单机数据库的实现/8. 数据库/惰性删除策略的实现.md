1. `expireIfNeeded` 函数负责实现**惰性删除**。所有读写键空间的 Redis 命令在执行之前，都会先调用这个函数，对输入键进行检查。
    
2. 函数执行时有以下两种情况：
    
    - 如果键已过期，则删除该键
        
    - 如果键未过期，则不执行任何操作
        
3. 因为每个键都可能被 `expireIfNeeded` 函数删除，所以每个命令的实现函数都必须能同时处理键存在与不存在两种情况。
    
4. 执行流程为：读写命令执行前 → 调用 `expireIfNeeded` 函数 → 判断键是否过期 → 过期则删除键，未过期则继续执行命令本身的操作。
    
5. 从命令的角度看，完整流程是：
    
    - 键是否存在？不存在 → 直接返回空回复
        
    - 键存在 → 是否已过期？已过期 → 删除键，返回空回复
        
    - 键存在且未过期 → 执行命令本身的操作，返回对应值
