1. 在Securtity 这个依赖/环境中 给Spring提供了以下的安全特性 特性如下:
   1.1 所有的HTTP请求路径都需要认证；
   1.2 不需要特定的角色和权限
   1.3 没有登录页面
   1.4 认证过程是通过HTTP basic认证对话框实现的
   1.5 系统只有一个用户，名字叫user
2. 有时候,Security提供的特性并不是我们所需的，所以我们为此可能或许需要改其三个特性:
    2.1 通过登录页面来提示用户进行认证，而不是HTTP basic
    2.2 提供多个用户，为其提供一个注册页面(这个是常用方法);
    2.3 对不同的请求路径，执行不同的安全规则，有些需要额外的认证，有些则根本不需要认证
3. Security同样为用户存储提供了多个可选方案 包括:
   3.1[[ 基于内存的用户存储]](可能会遗失的风险)
   3.2 基于JDBC的用户存储(JDBC已经被Mybatis代替)
   3.3 [[以LDAP作为后端的用户存储]]
   3.4 [[自定义用户详情服务]]
   3.5  无论使用其中哪个方法 都可以通过覆盖WebSecurityConfigurerAdapter基础配置类中定义的configure()方法来进行配置
