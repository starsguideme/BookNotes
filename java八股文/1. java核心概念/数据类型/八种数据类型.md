

**Java 的数据类型**

### 一、两大分类

Java 的数据类型大致可以分为两类：**基本数据类型**和**引用数据类型**。

| 分类 | 说明 |
|------|------|
| ==**基本数据类型**== | 直接存储值，不依赖对象，共 8 种 |
| ==**引用数据类型**== | 存储对象的引用，如类、接口、数组、枚举等 |

### 二、基本数据类型的分类

基本数据类型有八种，其可以分为三类：

| 分类 | 包含类型 |
|------|---------|
| ==**数值型**== | 整数类型（`byte`、`short`、`int`、`long`）和浮点类型（`float`、`double`） |
| ==**字符型**== | `char` |
| ==**布尔型**== | `boolean` |

### 三、各类型占用的字节数

| 类型 | 字节数 | 取值范围 |
|------|--------|---------|
| ==**`byte`**== | 1 字节 | -128 ~ 127 |
| ==**`short`**== | 2 字节 | -2^15 ~ 2^15 - 1 |
| ==**`char`**== | 2 字节 | 0 ~ 65535（无符号） |
| ==**`int`**== | 4 字节 | -2^31 ~ 2^31 - 1 |
| ==**`float`**== | 4 字节 | 科学计数法表示 |
| ==**`long`**== | 8 字节 | -2^63 ~ 2^63 - 1 |
| ==**`double`**== | 8 字节 | 科学计数法表示 |
| ==**`boolean`**== | JVM 规范未明确规定 | `true` / `false` |

### 四、修正说明

你笔记中提到的"`boolean` 占 1 字节"并不完全准确。在 Java 中，`boolean` 的大小在 JVM 规范中**没有明确规定**，不同的虚拟机实现不同：

-   在**单个 `boolean` 变量**中，通常使用 **int** 来表示（占 4 字节）。
-   在**`boolean[]` 数组**中，HotSpot JVM 使用 **byte** 来表示（占 1 字节）。

### 五、面试要点

| 问题                   | 回答                                                            |
| -------------------- | ------------------------------------------------------------- |
| **Java 的数据类型分为哪两大类** | ==**基本数据类型**== 和 ==**引用数据类型**==                               |
| **基本数据类型有哪八种**       | `byte`、`short`、`char`、`int`、`float`、`long`、`double`、`boolean` |
| **`boolean` 占几个字节**  | ==**JVM 规范未明确规定**==，单个通常用 int（4 字节），数组中用 byte（1 字节）           |
| **基本数据类型的三个分类**      | ==**数值型（整数+浮点）、字符型、布尔型**==                                    |
