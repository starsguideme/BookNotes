信号量是一种**计数器**，用来控制同时访问某个资源的线程数量。它和[[互斥量]]的核心区别在于：

| 机制          | 模型           | 作用                         |
| ----------- | ------------ | -------------------------- |
| ==**互斥量**== | 一把钥匙（0 或 1）  | 保证**独占**，同一时刻只有一个线程能访问     |
| ==**信号量**== | 一个计数器（可大于 1） | 保证**限流**，允许多个线程同时访问，但不超过上限 |
|             |              |                            |

信号量通过两个原子操作来控制访问：

- **P 操作（申请）**：线程想要访问资源时，执行 P 操作。如果计数器大于 0，计数器减 1，线程获得访问权限；如果计数器为 0，线程进入等待队列。
    
- **V 操作（释放）**：线程访问完毕后，执行 V 操作，计数器加 1。如果等待队列中有线程，唤醒其中一个。
    

当信号量的最大值设置为 1 时，它就和互斥量功能一样，保证独占访问。当最大值大于 1 时，它允许多个线程同时访问资源池，起到**限流**的作用。Java 中的 `Semaphore` 类就是信号量的具体实现。
