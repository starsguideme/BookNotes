该系统是为本地生活服务设计的全栈外卖平台，涵盖用户下单、商家管理、实时配送等核心业务。针对高并发下的数据一致性和系统性能瓶颈，进行了深度优化。

### **核心技术点**

- **高性能缓存设计（Redis）** 针对小时级订单统计等高频查询，设计了基于 **Redis Hash** 的缓存方案，通过减少冗余的 MySQL 联表查询，使核心接口响应时间大幅缩短。经 **JMeter** 压力测试，系统 QPS 提升了 **300%**。
    
- **高并发库存防超卖（乐观锁）** 针对爆款菜品抢购场景，采用 **Redis 预扣库存 + Lua 脚本** 保证操作原子性，配合数据库 **CAS 乐观锁** 实现双重保障，彻底杜绝了超卖风险，并支撑了单机 **2000+ QPS**。
    
- **业务幂等性设计（防重方案）** 在超时订单自动恢复库存的定时任务中，设计了“**数据库标记字段 + Redis 幂等记录器**”的防重方案。通过 **Spring 事务** 确保逻辑原子性，解决了网络波动导致的重复处理风险。
    
- **轻量级认证架构（JWT 替代方案）** 基于单体架构与 RBAC 模型需求，独立设计并实现了基于 **JWT + 自定义拦截器** 的认证链路。针对 Token 续期、注销及权限校验进行了自研开发，相较于 Spring Security 显著降低了系统复杂度与内存开销。
    
- **高可靠购物车方案（双写架构）** 针对购物车高频读写场景，采用 **Redis + MySQL 双写策略**。利用 **Redis Lua 脚本** 封装“读-改-写”原子操作解决并发丢数问题，并针对大 Key 风险采用**摘要缓存策略**，将接口响应时间从 **80ms 降至 15ms**。
