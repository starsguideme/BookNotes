
### 一、核心定义

大对象就是指需要**大量连续空间**的 Java 对象，比如说**字符串**或**元素很庞大的数组**。在为其进行分配空间的时候，它更容易导致**提前触发 GC**。

### 二、大对象的分配策略

复制对象时，由于大对象意味着**高额的内存复制开销**，虚拟机通过设置参数（如 `-XX:PretenureSizeThreshold`），可以指定大于什么阈值的对象**直接放入老年代**，这样可以避免在多个区域中来回复制对象。

| 参数                                   | 说明                                   |
| ------------------------------------ | ------------------------------------ |
| ==**`-XX:PretenureSizeThreshold`**== | 指定对象大小的阈值，超过该阈值的对象直接分配到老年代，避免在新生代中复制 |

### 三、面试要点

| 问题            | 回答                                                       |
| ------------- | -------------------------------------------------------- |
| **什么是大对象**        | 需要**大量连续空间**的 Java 对象，如长字符串、大数组                          |
| **大对象为什么容易触发 GC** | 分配时需要大量连续空间，新生代空间不足时**提前触发 GC**                          |
| **大对象的分配策略**      | 通过 `-XX:PretenureSizeThreshold` 指定阈值，超过阈值的对象**直接分配到老年代** |
| **大对象的复制开销**      | 复制大对象意味着**高额的内存复制开销**，因此直接分配到老年代可避免来回复制                  |
