

**jstack 工具**

### 一、核心作用

`jstack` 命令用于生成虚拟机当前时刻的**线程快照**，一般称为 **thread dump** 或 **javacore** 文件。线程快照是当前虚拟机内**每一条线程**正在执行的方法堆栈的集合。

生成线程快照的目的通常是定位线程出现**长时间处于 GC 停顿**的问题。如果线程出现停顿时，通过 `jstack` 来查看各个线程的调用堆栈，就可以知道每个没响应的线程的此刻状态了。

### 二、命令格式

```bash
jstack [option] vmid
```

### 三、各选项说明

| 选项 | 说明 |
|------|------|
| ==**`-F`**== | 当正常输出的请求不被响应时，**强制输出线程堆栈** |
| ==**`-l`**== | 除堆栈外，显示关于锁的**附加信息**（如死锁检测） |
| ==**`-m`**== | 如果调用到本地方法的话，可以显示 **C/C++ 的堆栈** |

### 四、线程快照的替代方法

自从 JDK 5 之后，`Thread` 类新增了一个 `getAllStackTraces()` 方法，用于获取虚拟机中所有线程的 `StackTraceElement` 对象。开发者可以通过编程的方式在程序内部获取线程堆栈信息，而不必依赖 `jstack` 命令行工具。
