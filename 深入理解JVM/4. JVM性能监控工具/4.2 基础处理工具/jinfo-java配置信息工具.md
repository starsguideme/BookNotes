
### 一、核心作用

`jinfo` 作用是**实时查看**和**调整虚拟机的各种参数**。

-   使用 `jps` 命令的 `-v` 参数可以查看虚拟机启动时**显式指定**的参数列表。
-   但如果想查看**隐式的默认值**，除了查找资料外，几乎也只能使用 `jinfo` 的 `-flag` 选项进行查询了。

### 二、命令格式

```bash
jinfo [options] pid
```

### 三、常用选项

| 选项 | 说明 |
|------|------|
| ==**`-flag <name>`**== | 查看指定参数的**当前值**，如 `jinfo -flag MaxHeapSize <pid>` |
| ==**`-flag +<name>`**== | 开启指定参数的布尔值 |
| ==**`-flag -<name>`**== | 关闭指定参数的布尔值 |
| ==**`-flag <name>=<value>`**== | 设置指定参数的值（部分参数运行时可以动态调整） |
| ==**`-sysprops`**== | 把虚拟机进程的 `System.getProperties()` 的内容打印出来，即 JVM 的系统属性 |
| ==**`-flags`**== | 打印所有 JVM 参数的默认值和设置值 |

### 四、面试要点

| 问题                            | 回答                                                             |
| ----------------------------- | -------------------------------------------------------------- |
| **`jinfo` 工具的作用**                 | ==**实时查看和调整虚拟机参数**==                                           |
| **如何查看隐式的默认值**                    | 使用 `jinfo` 的 ==**`-flag`**== 选项                                |
| **`-sysprops` 选项的作用**             | 打印 ==**`System.getProperties()`**== 的内容                        |
| **`jps -v` 和 `jinfo -flags` 的区别** | `jps -v` 只显示**显式指定**的参数；`jinfo -flags` 显示**所有** JVM 参数的默认值和设置值 |
