
### 一、核心作用

`jmap` 命令用于生成**堆转储快照**（也就是 heap dump 或 dump）。如果不使用 `jmap` 命令，要想获取 Java 堆转储快照，也可以通过一些其他手段（如 JVM 启动时配置 `-XX:+HeapDumpOnOutOfMemoryError` 在 OOM 时自动生成）。

`jmap` 的作用不仅是为了获取堆转储，还可以查询 **finalize 执行队列**、查看堆的详细配置等。

### 二、Windows 平台的功能受限

和 `jinfo` 一样，`jmap` 在 Windows 上的功能也遭受了阉割。除了以下两个选项在所有操作系统中都可以使用之外，其余功能都只能在 **Linux 和 Solaris** 中使用：

| 选项               | 说明                        | Windows 是否支持 |
| ---------------- | ------------------------- | ------------ |
| ==**`-dump`**==  | 生成堆转储快照                   | ==**支持**==   |
| ==**`-histo`**== | 查看每个类的实例数量、空间占用统计         | ==**支持**==   |
| `-finalizerinfo` | 查看等待执行 `finalize()` 方法的对象 | 不支持          |
| `-heap`          | 查看堆的详细配置                  | 不支持          |
| `-permstat`      | 查看永久代（JDK 8 之前）的类加载情况     | 不支持          |
| `-F`             | 强制生成堆转储                   | 部分支持         |

### 三、命令格式

```bash
jmap [option] vmid
```

### 四、各选项说明

| 选项                       | 说明                                                        |
| ------------------------ | --------------------------------------------------------- |
| ==**`-dump`**==          | 生成 Java 堆转储快照，格式为 `-dump:[live,]format=b,file=<filename>` |
| ==**`-finalizerinfo`**== | 显示在 **F-Queue** 中等待 `finalize()` 方法执行的对象                  |
| ==**`-heap`**==          | 显示 Java 堆的详细信息，如使用哪种 GC、堆配置、分代情况                          |
| ==**`-histo`**==         | 显示堆中对象的统计信息，包括类名、实例数量、总容量                                 |
| ==**`-permstat`**==      | 以 ClassLoader 为统计口径，显示永久代中类的装载情况                          |
| ==**`-F`**==             | 当 `-dump` 没有响应时，强制生成堆转储快照                                 |

### 五、面试要点

| 问题                    | 回答                                              |
| --------------------- | ----------------------------------------------- |
| **`jmap` 工具的作用**          | ==**生成堆转储快照**==，查看 finalize 执行队列，查看堆配置          |
| **Windows 上支持哪两个选项**      | ==**`-dump`**== 和 ==**`-histo`**==              |
| **`-dump` 选项的格式**         | `-dump:[live,]format=b,file=<filename>`         |
| **什么情况下需要强制生成堆转储**        | 当 `-dump` 没有响应时，使用 ==**`-F`**== 强制生成            |
| **除了 `jmap` 还有什么方式获取堆转储** | 启动时配置 ==**`-XX:+HeapDumpOnOutOfMemoryError`**== |
