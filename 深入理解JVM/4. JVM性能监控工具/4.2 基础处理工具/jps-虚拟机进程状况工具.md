

**jps 工具**

### 一、核心作用

`jps` 工具可以通过列出正在运行的虚拟机进程，并显示虚拟机执行主类名称以及这些进程的本地 JVM 的 PID。虽然该工具功能单一，但却是**使用率最高的命令行工具**，因为其他的 JDK 工具大多需要输入本地虚拟机唯一 ID（LVMID）来确定要监控的是哪个虚拟机进程。可这对于 LVMID 来说过于麻烦，因此可以使用 PID 来查主类的功能。

### 二、命令格式

```bash
jps [options] [hostId]
```

### 三、常用选项

| 选项 | 说明 |
|------|------|
| ==**`-l`**== | 输出主类的**全限定名**（包括包名），如果是 jar 包则输出 jar 的完整路径。**最常用** |
| ==**`-q`**== | 只输出 **PID**，不输出主类名称 |
| ==**`-v`**== | 输出虚拟机进程启动时的 **JVM 参数** |
| ==**`-m`**== | 输出传给主类 **main 方法**的参数 |

### 四、面试要点

| **问题**                     | 回答                                     |
| ---------------------- | -------------------------------------- |
| **`jps` 工具的作用**            | 列出正在运行的 Java 进程，显示**主类名称**和**PID**     |
| **`jps -l` 的作用**           | 输出主类的**全限定名**，最常用                      |
| **为什么 `jps` 是使用率最高的命令行工具** | 其他 JDK 工具需要输入 LVMID，而 `jps` 可以快速获取 PID |
| **`jps -v` 的作用**           | 查看虚拟机进程启动时的 **JVM 参数**                 |
