
### 一、核心作用

`jstat` 是一个比较常用的监视虚拟机性能问题的常用工具。可以监控**类加载、垃圾回收、运行时编译**等方面的信息。

### 二、命令格式

```bash
jstat [options] vmid [interval [s|ms] [count]]
```

**VMID 与 LVMID 的区别**：

| 场景              | VMID 格式                                              |
| --------------- | ---------------------------------------------------- |
| ==**本地虚拟机进程**== | VMID 与 LVMID 是一样的，直接使用 PID                           |
| ==**远程虚拟机进程**== | `[protocol:] [//]lvmid[@hostname[:port]/servername]` |

**interval 和 count 参数**：代表查询间隔与次数。如果这两个参数不设置任何值，则其默认查询次数是 **1 次**。

### 三、options 分类

`jstat` 的 options 比 `jps` 要多多了，大致可以分为三类：

| 类别            | 说明            | 常用选项                            |
| ------------- | ------------- | ------------------------------- |
| ==**类加载**==   | 监控类的加载、卸载和总耗时 | `-class`                        |
| ==**GC**==    | 监控 GC 的详细情况   | `-gc`、`-gcutil`、`-gccause` 等    |
| ==**运行时编译**== | 监控 JIT 编译情况   | `-compiler`、`-printcompilation` |

### 四、所有 options 说明

| 选项                          | 说明                                    |
| --------------------------- | ------------------------------------- |
| ==**`-class`**==            | 类加载统计：加载/卸载数量、总空间、类装载耗时               |
| ==**`-gc`**==               | 堆内存各区域容量和 GC 统计                       |
| ==**`-gccapacity`**==       | 堆内存各区域的最大、最小容量                        |
| ==**`-gcutil`**==           | 堆内存各区域使用率百分比，**最常用**                  |
| ==**`-gccause`**==          | 与 `-gcutil` 类似，但额外输出**上一次/本次 GC 的原因** |
| ==**`-gcnew`**==            | 新生代 GC 详细统计                           |
| ==**`-gcnewcapacity`**==    | 新生代各区域的容量信息                           |
| ==**`-gcold`**==            | 老年代 GC 详细统计                           |
| ==**`-gcoldcapacity`**==    | 老年代的容量信息                              |
| ==**`-gcmetacapacity`**==   | 元空间的容量信息（JDK 8 之前叫 `-gcpermcapacity`） |
| ==**`-compiler`**==         | JIT 编译器编译耗时、失败类型等信息                   |
| ==**`-printcompilation`**== | 最近被 JIT 编译的方法信息                       |

### 五、面试要点

| 问题                              | 回答                                                   |
| ------------------------------- | ---------------------------------------------------- |
| **`jstat` 工具的作用**                   | 监控虚拟机**类加载、GC、运行时编译**等信息                             |
| **`jstat` 最常用的 options**            | ==**`-gcutil`**==，查看堆内存各区域使用率百分比                     |
| **`interval` 和 `count` 不设置时默认查询几次** | ==**1 次**==                                          |
| **`-gccause` 比 `-gcutil` 多输出什么**    | ==**GC 的原因**==                                       |
| **远程虚拟机进程的 VMID 格式**                | `[protocol:] [//]lvmid[@hostname[:port]/servername]` |
