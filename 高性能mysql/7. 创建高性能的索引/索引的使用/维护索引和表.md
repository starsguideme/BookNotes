
### 一、维护表的三个目的

在通常情况下，即使用正确的数据类型创建了表并为其加上了合适的索引，工作也没有结束，依旧需要维护表和索引。维护表的目的有三个：

| 目的 | 说明 |
|------|------|
| ==**找到并修复损坏的表**== | 检查表的完整性，发现并修复因硬件故障、MySQL 崩溃等原因导致的表损坏 |
| ==**维护准确的索引统计信息**== | 保持索引统计信息的准确性，帮助优化器生成更优的查询计划 |
| ==**减少不连续的空间**== | 通过碎片整理，减少表或索引中的不连续空间，提升 I/O 性能 |

### 二、维护表的方法

| 方法                       | 说明                      |
| ------------------------ | ----------------------- |
| ==**`CHECK TABLE`**==    | 检查表是否损坏                 |
| ==**`REPAIR TABLE`**==   | 修复损坏的表                  |
| ==**`ANALYZE TABLE`**==  | 更新索引统计信息，帮助优化器生成更优的查询计划 |
| ==**`OPTIMIZE TABLE`**== | 整理表碎片，减少不连续空间，提升 I/O 性能 |
