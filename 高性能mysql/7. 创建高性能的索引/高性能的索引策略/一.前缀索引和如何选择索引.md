1. 前缀索引就是只进行字段的前一部分进行索引，这样做有个缺点就是会降低索引的选择性，索引的选择性是指不重复的索引值和数据表的记录总数的比值，如果索引的选择性越高则查询效率也就越高，一般是0~1的范围 当比值是1的时候 也就是其性能最好的时候；如下是怎么确定什么是合适的前缀长度的方式:
-- 计算完整列的选择性（作为基准）
SELECT COUNT(DISTINCT column) / COUNT(*) FROM table;

-- 计算前缀长度为 N 时的选择性
SELECT COUNT(DISTINCT LEFT(column, N)) / COUNT(*) FROM table;
2.  一般情况下，列前缀的选择性也是足够高的，足以满足查询时的性能需求，对于长VARCHAR类型的列，必须使用前缀索引，因为mysql不支持这些列的完整索引，为了降低选择度则会需要两种情况，一个是无法使用覆盖索引的时候，另一个则是因为**无法用于 ORDER BY / GROUP BY**
3. 如果要选择足够长的前缀以保证较高的选择性，同时字符也不能太长导致空间的浪费，前缀应该足够长，如果前缀是主串的最长子串的时候 性能最好.
