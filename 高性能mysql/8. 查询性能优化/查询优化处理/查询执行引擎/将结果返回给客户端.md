
### 一、核心流程

执行查询的最后一个阶段其实就是**将数据返回给客户端**。即使查询不需要给客户端返回结果集，MySQL 依然会返回这个查询的**一部分数据**（如 `SELECT 1` 也会返回一个结果）。

### 二、增量返回的好处

MySQL 将结果集返回给客户端的操作是一个**增量且逐步返回**的过程，这样的好处有两个：

| 好处 | 说明 |
|------|------|
| ==**服务器端无需存储太多数据**== | 不需要把整个结果集一次性缓存在内存中，因此不会消耗太多内存 |
| ==**客户端可以第一时间获得结果**== | 让客户端尽早收到查询结果，不需要等到全部数据生成完毕 |

### 三、数据传输机制

该结果集中每一行数据都会以一个满足 **MySQL C/S 通信协议**的**封包**发送，再通过 **TCP** 进行**分包和组包**的操作后进行批量传输。

```text
① 查询执行完成，生成结果集
    ↓
② 结果集以增量方式逐行返回
    ↓
③ 每行数据封装成符合 MySQL C/S 协议的封包
    ↓
④ 通过 TCP 进行分包和组包
    ↓
⑤ 批量传输给客户端
```

### 四、面试要点

| 问题             | 回答                                         |
| -------------- | ------------------------------------------ |
| **MySQL 返回结果集的方式** | ==**增量且逐步返回**==                            |
| **增量返回的两个好处**      | ==**服务器端无需存储太多数据**== 和 ==**客户端第一时间获得结果**== |
| **结果集通过什么协议传输**    | **MySQL C/S 通信协议** + **TCP**               |
