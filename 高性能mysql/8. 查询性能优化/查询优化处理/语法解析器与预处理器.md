
### 一、解析器的核心作用

MySQL 通过**关键字**将 SQL 语句进行解析，并生成一颗对应的**解析树**。MySQL 解析器将使用 MySQL 语法规则**验证和解析查询**。

### 二、解析器检查的内容

| 检查项                 | 说明                       |
| ------------------- | ------------------------ |
| ==**错误的关键字**==      | 检查是否使用了不存在或拼写错误的关键字      |
| ==**关键字的顺序是否正确**==  | 检查 SQL 语句中关键字的排列是否符合语法规则 |
| ==**引号是否能前后正确匹配**== | 检查字符串引号、单引号、双引号是否正确闭合    |

### 三、预处理器的检查

将这一系列的东西会被**预处理器**检查，查看是否存在无法被解析的语句。预处理器会进一步检查：

| 检查项 | 说明 |
|--------|------|
| ==**表是否存在**== | 验证 SQL 中引用的表是否真实存在 |
| ==**字段是否存在**== | 验证 SQL 中引用的字段是否在对应的表中 |
| ==**权限校验**== | 检查当前用户是否有执行该操作的权限 |

### 四、面试要点

| **问题**           | 回答                               |
| ------------ | -------------------------------- |
| **MySQL 解析器的作用** | 使用**语法规则验证和解析查询**，生成**解析树**      |
| **解析器检查哪些内容**    | ==**错误关键字、关键字顺序、引号匹配**==         |
| **预处理器检查哪些内容**   | ==**表是否存在、字段是否存在、权限校验**==        |
| **解析器和预处理器的区别**  | 解析器检查**语法**是否正确；预处理器检查**语义**是否正确 |
