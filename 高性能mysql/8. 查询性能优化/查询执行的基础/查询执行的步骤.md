
### 一、执行步骤

当希望 MySQL 能够以更高性能运行查询时，最好的办法是弄清 MySQL 是如何优化和执行查询的。一般情况下，MySQL 执行一个查询的过程，会执行以下步骤：

```text
① 客户端给服务器发送一条 SQL 语句
    ↓
② 服务器端进行 SQL 语句解析、预处理，再由优化器生成对应的执行步骤
    ↓
③ MySQL 根据优化器生成的执行计划，并由存储引擎的 API 来执行
    ↓
④ 将结果返回给客户端
```

### 二、各步骤详解

| 步骤                     | 说明                                 |
| ---------------------- | ---------------------------------- |
| ==**1. 客户端发送 SQL**==   | 客户端通过**网络连接**将 SQL 语句发送给 MySQL 服务器 |
| ==**2. 解析与预处理**==      | 词法分析、语法分析生成解析树；预处理器检查表名、字段名是否正确    |
| ==**3. 查询优化器生成执行计划**== | 优化器决定使用哪个索引、表的连接顺序等，生成最优的执行计划      |
| ==**4. 存储引擎执行**==      | 通过存储引擎的 API，根据执行计划从磁盘读取数据          |
| ==**5. 返回结果**==        | 服务器将查询结果通过网络返回给客户端                 |

### 三、面试要点

| 问题              | 回答                                                     |
| --------------- | ------------------------------------------------------ |
| **MySQL 执行查询的关键步骤** | ==**客户端发送 SQL → 解析与预处理 → 优化器生成执行计划 → 存储引擎执行 → 返回结果**== |
| **查询优化器的作用**        | 决定使用哪个**索引**、表的**连接顺序**等，生成最优执行计划                      |
| **执行计划由谁生成**        | ==**查询优化器**==                                          |
| **存储引擎负责什么**        | 根据执行计划，通过**存储引擎 API** 从磁盘读取数据                          |
